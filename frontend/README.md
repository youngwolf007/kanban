# Kanban Board

A single-board Kanban project manager. Next.js, TypeScript, Tailwind CSS, client-rendered, no backend.

## Features

- One board with 5 fixed, renameable columns
- Cards with a title and details, added and deleted per column
- Drag and drop to move cards within and across columns
- Seeded with dummy data on load; no persistence

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Testing

```bash
npm test        # unit tests (Vitest)
npm run test:e2e  # end-to-end tests (Playwright)
```

## Build

```bash
npm run build
npm start
```
